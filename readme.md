Курсовая работа студента 1 курса Носиковой М.С группы 4750601/50001 по теме "Многофункциональный расчёт GC-состава"

Что делает программа:
- читает ДНК-последовательность из FASTA-файла
- считает общий % GC-состава
- строит скользящий профиль по окнам
- показывает график с помощью "matplotlib"

Как запустить?
1. Установите зависимости (если нет)
pip install matplotlib
2. Запустите скрипт
py course_work_nosikova.m.s.py
